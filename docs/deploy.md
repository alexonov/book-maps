# Deploy

`main` is at `https://github.com/alexonov/book-maps`.

```bash
cd ~/Documents/projects/book-maps
git push -u origin HEAD
```

Then [Vercel](https://vercel.com/new) → Import `alexonov/book-maps` → Deploy. No environment variables. The map uses public OpenStreetMap tiles.

See [project context](project-context.md).
